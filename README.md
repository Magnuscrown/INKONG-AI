# INKONG AI

Live Platform: https://inkong-ai.vercel.app

INKONG AI is an all-in-one hub featuring private AI chat, web search, video and audio-to-text conversion, plus entertainment options—all in one place.

---

## 🚀 Overview

This project is a modular, high-performance web application designed for versatility. By separating concerns into distinct files, I’ve ensured the codebase is maintainable, scalable, and easy to navigate for any potential collaborator or hiring manager.

## 📁 Repository Structure

- `index.html`: Main landing page architecture.
- `about.html`, `faq.html`, `privacy.html`, `terms.html`: Dedicated pages for user information and compliance.
- `app.js`: Core logic for AI interactions and dynamic content handling.
- `style.css` & `page.css`: Modular styling for responsive design across all devices.
- `movies.json`: Structured data management for the entertainment suite.
- `vercel.json`: Deployment configuration for optimized performance.

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **AI Integration:** API-driven search and processing
- **Architecture:** Modular component-based file structure
- **Deployment:** Vercel

## ✨ Key Features

- **Centralized Hub:** Seamless transition between utility, research, and entertainment tools.
- **Privacy-First AI:** Secure interactions for sensitive queries.
- **Media Utilities:** Advanced video and audio-to-text conversion.
- **Responsive Architecture:** Built with mobile-first design principles.
